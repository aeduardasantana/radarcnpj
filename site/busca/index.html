Base pesquisável

Origem dos resultados: dados que você importar neste navegador. Não é uma consulta automática a todas as empresas do Brasil. Para cobertura nacional, será necessário conectar uma base indexada da Receita Federal no servidor.

Importe um arquivo CSV de estabelecimentos (com cabeçalho) contendo pelo menos cnpj ou cnpj_basico + cnpj_ordem + cnpj_dv. Suporta colunas comuns como razao_social, nome_fantasia, uf, municipio, cnae, data_abertura, situacao_cadastral, mei.

A base utiliza IndexedDB neste dispositivo. Limpeza de dados do navegador pode apagar registros. Evite importar dados pessoais não necessários. Os microdados oficiais da Receita podem exigir tratamento e junção de tabelas antes da importação.
